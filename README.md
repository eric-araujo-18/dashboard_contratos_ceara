# Dashboard de Contratos Públicos do Ceará

Plataforma para visualização e detecção de comportamentos atípicos
em contratos públicos dos municípios do Ceará.

## Tecnologias

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Isolation Forest
- D3.js
- GeoJSON
- PNCP
- IBGE
